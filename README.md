## 🇩🇪 Deutsch

Meine persönliche Portfolio-Website. Eine Single-Page-Visitenkarte mit Lebenslauf,
Publikationen, Projekten und akademischem Werdegang — gebaut mit purem HTML, CSS

## 🇬🇧 English

My personal portfolio website. A single-page visiting card featuring my
background, publications, projects, and academic history — built with plain
HTML, CSS, and JavaScript, no frameworks. Features custom scroll-driven
animations, a generative fractal background, and a bilingual interface (EN/DE).
